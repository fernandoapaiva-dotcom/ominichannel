Política de Privacidade — OminiChannel

Última atualização: 02/10/2026

O OminiChannel é um sistema interno de atendimento ao cliente via WhatsApp, usado pela Servweld e Centro-Oeste (Servsolda) para gerenciar conversas, ordens de serviço e automações de atendimento. Esta política descreve como os dados são tratados dentro do aplicativo.

Quem usa este aplicativo

O OminiChannel é de uso interno: destinado a funcionários (atendentes, técnicos e administradores) da Servweld/Servsolda. Não é um aplicativo de uso público nem distribuído para o público em geral.

Dados coletados

  • Dados de contato de clientes (nome, telefone) que entram em contato via WhatsApp;
  • Conteúdo de mensagens trocadas (texto, áudio, imagens, documentos) para fins de atendimento;
  • Dados de Ordens de Serviço (O.S.) vinculadas ao atendimento: equipamento, status, histórico e peças;
  • Dados de login dos funcionários (nome de usuário/PIN) para controle de acesso ao sistema.

Uso dos dados

Os dados são usados exclusivamente para prestar o atendimento ao cliente, automatizar avisos sobre o andamento de Ordens de Serviço e manter o histórico de atendimento. Não há compartilhamento com terceiros para fins de publicidade, e não há venda de dados.

Armazenamento e segurança

Os dados são armazenados em servidor próprio da empresa, com acesso restrito a funcionários autorizados mediante login.
